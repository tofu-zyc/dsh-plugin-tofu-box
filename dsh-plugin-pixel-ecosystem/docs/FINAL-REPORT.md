# 最终答卷 · 像素生态缸 0.3「能量账本」

> 一句话：把"靠调数值撑住的种群曲线"换成"由能量流撑住的食物网"。
> 本文是这次重写的交付说明：改了什么、为什么这么改、怎么验证、还差什么。

---

## 1. 起点：0.2.x 到底坏在哪

不是"数值没调好"，是**四个结构性缺陷**。每一个都能用数据指出来：

| # | 缺陷 | 证据（旧引擎实测） |
|---|---|---|
| 1 | **决策从不读身体**：`entity.energy`（会死人的那个数）在整个决策层出现 0 次 | 3501 例饿死里，**77% 死时 `hunger ≤ 0.6`**——它自己并不觉得饿；1554 例**站在草地上**饿死 |
| 2 | **两本账**：`energy` 管生死、`needs.hunger` 管决策，只靠两行代码勉强同步 | 于是"饿"是个计时器（0→1 需 95 秒），不是传感器 |
| 3 | **行为没有时长**：决策每 0.22–0.55 秒全量重掷，意图没有完成条件 | 意图驻留中位数 **0.8 秒**，休息占 69%，路径方向性 0.28（≈随机游走） |
| 4 | **世界是均匀地毯**：草量恒定 0.96、满图同质 | 没有理由移动 → 动物中位行程 900 秒只有 30 格 |

再加一条**流程**上的：唯一能测行为的工具（`.scratch/balance.mjs`）已经不在仓库里，测试里**一条行为断言都没有**。所以"调数值"不是态度问题，是当时唯一能用的手段。

## 2. 改成了什么

### 2.1 一条能量账本（P1，sim-core）

- `body` = `{E 储备, V 结构, M 成熟度, health, fatigue}`，单位是 **kJ**。
- `metabolise()` 是**唯一**能改 `body.E` 的函数；`hunger` 变成 `1 − E/Emax` 的只读视图 —— **两本账在结构上被消灭**，不是靠纪律。
- 所有数值从物理推出：代谢率用 Nagy 1999 的实测异速方程，摄入用 Holling II + 处理时间，繁殖价 = 整胎质量的能量 ÷ 0.8 的转换效率，生命史按"年"书写再换算。
- **自校验**：2 kg 兔子推出 182 g 干物质/日，与真实兔子（100–200 g）吻合；60 kg 鹿推出 2.2 kg/日，同样吻合。这说明方程可以照搬，不是凑出来的。

### 2.2 决策系统（P2，behaviour）

四层：**感知 → 信念 → 驱动力 → 审议 → 执行**。

- 感知：1 Hz 错峰的真实栅格扫描（取代"12 次随机抽样"），结果写进带时间戳的 `belief`，会过期。
- 驱动力：八个（饿/渴/冷/疲劳/恐惧/社交/好奇/性），**每一个都由身体或处境导出**，没有一个计时器。
- 审议：只在状态边界或中断时打分，`Σ 权重×驱动×机会质量 × 行程效率 − 预计能量成本`。
- 执行：状态机，每状态有 `min/duration/完成条件`，走不动 1.3 秒×2 就放弃；只有"要命的事"能打断承诺。

### 2.3 世界有了结构（P1 + P3，sim-core + render）

- 植物改质量单位（kg 干物质/m²），生长受**光（Beer-Lambert 自遮荫+树冠）、水、养分**三重限制，站高**涌现**：p10 0.19 / p50 0.28 / p90 0.52 —— 5–6 倍的摄入差，动物终于有理由走过去。
- 水草受**深度+底光**限制，深水保持开阔（depth > 0.6 时草量为 0）。
- 气候成为唯一时间来源：`world.climate` 提供昼夜/季节/温度，**别的系统不许自己再推一遍**。

## 4. 捕食者密度的故事（这次最有价值的一条）

0.2.x 文档反复说"捕食层一直半饿着，调 huntReach/meatGain 调不平"。
用能量学算一次就明白了：

- 捕食需求 424 GJ/年，猎物**年产量**只有 ~15 GJ/年 → **超支 8 倍**。
- 捕食者生物量 : 猎物生物量 = **45%**（自然界是 1–5%）。
- 实测：**98.9% 的捕食者死亡是饿死**，而种群靠移民系统每 25 秒传送 4–8 只吊着。

这不是参数问题，是**热力学**：0.2 km² 养不活 8 只狼 + 4 只熊（真实狼领地 100–1000 km²）。
修法不是调 `meatGain`，而是：**按猎物产量反推捕食者数量** + 提高世界产能 + **移民群体按物种下限缩放**（原来固定 4–8 只，对下限=1 的物种等于每次灌进 8 倍）。

修完之后捕食者**第一次真正繁殖**：狐 11 胎、狼 9 胎、狗鱼 9 胎。

## 6. 还差什么（诚实清单）

1. **棕熊 10 日内不繁殖**——36 天成熟是"1 年=8 游戏日"的直接推论；要么接受，要么给它单独一个世代压缩常数（我倾向接受）。
2. **乌鸦偏弱**：靠放宽食腐半径（1.7→4.0）才勉强够到繁殖储备，长期看还需要"杂食"（吃昆虫/果实）这条路径。
3. **大型物种的冬眠/迁徙**没有做。
4. **美术**：动物在远景偏小、树冠层次、草地色调都还能再打磨一轮。
5. **P3.2 门禁仍是 info**：捕食者饿死占比在小样本下噪声太大，没法定成硬门禁。

## 8. 0.3.x 修复记录（2026-11-08）

这一版没有加新玩法，全部是"面板能用"的问题。列出来是因为其中三条是**流程性错误**，比代码本身更值得记。

### 8.1 画布只画左上角一小块（P0）

**根因**：带存档启动时世界要异步解包，面板的 `attach()` 先执行，而 `ensureBuffers()` 开头 `if (world === null) return` —— 放大用的离屏画布永远没被创建，`draw()` 落入 1:1 分支，把画布尺寸算成"格数"而不是"格数 × 缩放"。

**几何指纹**：舞台 974 宽、缩放 3 → 974/3 = 324，画面上那块正好 324×247，与玩家截图一致。

**为什么"时好时坏"**：新建世界是同步的（attach 时 world 已存在）；只有 gz 存档走 `DecompressionStream` 异步解包才触发。

**修法**：绘画的前置条件交还给绘画自己 —— `draw()` 每帧先 `ensureDrawBuffers()` 补齐 imageData / offscreen；backing store = `view.width × scale`（永远），CSS 盒 = 舞台尺寸，两者解耦。

**验收**（真浏览器，三路独立复现）：暖启动 `canvas 194×148 → 974×695`，`|stage − canvas| = 0`，四格矩阵（冷启动 / 切回 / resize / 隐藏再显示）全部 Δ0，`paint = 1.00`。

### 8.2 面板内的按钮点不动

舞台的 `pointerdown` 处理器对任何落在 `.pe-stage` 内的按下都调用 `preventDefault()` + `setPointerCapture()`，而引导卡、提示卡、空世界卡都渲染在舞台内部 → `pointerdown` 的 preventDefault 抑制了兼容鼠标事件，`click` 根本不会触发。现在按下点落在"面板 chrome"上时四个处理器直接返回。`tests/stage-controls.test.mjs` 钉住这张豁免表。

### 8.3 键盘被全局快捷键吃掉

`Space` 的守卫只判 `INPUT`，所以焦点在任意 `<button>` 上按空格时 `preventDefault()` 取消了按钮激活 —— 所有按钮对键盘失效，同时世界被暂停。现在守卫覆盖 `button / a / [role=button] / [contenteditable]`。

### 8.4 三条流程性错误（比 bug 更该记住）

1. **部署空转**：`dsh plugin add <tgz>` 在版本号未变时是空操作（pnpm 输出 `added 0`）。连续四轮"修复"从未到达浏览器。现在部署必须 ①递增版本号 ②比对部署目录 `client.js` 与本地构建的 SHA-256。面板标题栏常驻版本号，一眼可证伪。
2. **合成点击不算验证**：`element.click()` 跳过 `pointerdown`，恰好绕过了 8.2 那条 bug。现在 `tools/ui-smoke.mjs` 用 CDP `Input.dispatchMouseEvent` 发真输入。
3. **把"命令没报错"当成"改动生效"**：HTTP 200 + 页面里有插件名，只能证明插件注册了，不能证明是新的代码。

### 8.5 仍未解决

- **旧存档的捕食者过载**：0.3.0 时代狐 12 / 狼 5 / 熊 4，捕食者总需求约为猎物年产量 8 倍，几年内必然崩溃。新世界用校准后的配置（狐 4 / 狼 2 / 熊 1）。旧存档救不回来，只能重建。
- **多年期平衡未验证**：目前只做过一个游戏年的探针。多世代是否稳态，需要跑 5 年再下结论。
- **物种表行点击语义**：正在从"定位"改成"换笔刷 + 定位"（玩家期待"点这个物种 = 我要用它"）。
