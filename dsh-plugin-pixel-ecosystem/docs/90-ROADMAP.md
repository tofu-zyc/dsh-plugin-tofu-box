## P1 · 能量账本（sim-core）

气候 → 光照 → 植物 → 碎屑 → 个体代谢 → 摄食，一条竖切只跑 **草 + 兔**。

**门禁**
1. 能量守恒残差 < 1e-6（相对）
2. 兔的日食量落在 **182 g 干物质 ±20%**（物理自校验）
3. 出生 → 长大 → 繁殖 → 老死，四件事在 10 分钟观测里都出现过
4. **没有"站在草地上饿死"**：饿死个体的最后 30 秒必须满足 `hunger > 0.6`
5. 吞吐 ≥ 30 ticks/s @ 3000 实体
6. 存档 v2 往返一致（含体脂/成熟度/状态）

## P2 · 决策系统（behaviour）

感知 → 信念 → 驱动力 → 审议 → 执行状态机（含时长/承诺/中断/记忆）。

**门禁**
1. `rest` 时间占比从 69% 降到 **< 35%**
2. 意图驻留中位数从 1–3 s 升到 **> 10 s**
3. 路径有方向性：`净位移/路径长度 > 0.3`（现在是随机游走）
4. 决策抖动 < 12 次/分钟/只
5. 检视器能看到"当前状态 + 剩余时长 + 决策理由"

## P3 · 捕食成为过程（sim-core + behaviour）

Holling II + 处理时间 + 潜行/追击/脱逃/失败。

**门禁**：捕食成功率、平均追击时长可测；捕食者**不再全员饿死**（死因里 `starved` 占比 < 50%）。

## P4 · 季节与地形

温度场、Q10、地形运动成本、冬季食物短缺。

**门禁**：一年（8 日）内可见的物候变化；冬季死亡率显著高于夏季；检视器能显示"冷/饿"。

## P5 · 特性卡与屯粮

性状卡数据模型（照 Thrive 的 `{Inputs, Outputs}` 范式），**每张卡都要交租**；scatter hoarding + 偷食。

**门禁**：出现"藏食 → 回来取 → 被偷"的完整行为链。

## P6 · 打磨（render + ui）

按 `00-VISION.md` 的 G1–G7 清单逐条验收：引导、检视器、事件条、能量流面板、季节观感、笔刷反馈。
